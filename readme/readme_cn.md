## 📋 项目简介

本项目是一个基于 Web 的纽约时报（The New York Times）公开视频内容解析工具，支持从公开报道中提取媒体资源元数据，并提供多种格式的转换与本地保存选项。工具采用纯前端解析 + 后端代理的技术方案，无需安装客户端软件，开箱即用。

> ⚠️ **重要声明**：本工具仅用于个人学习、技术研究及合理使用场景。请遵守 [纽约时报服务条款](https://www.nytimes.com/content/help/rights/sale/terms-of-service.html) 及《美国版权法》等相关法规，尊重新闻机构与创作者的劳动成果，勿将下载内容用于商业用途或侵犯他人权益。本工具仅支持解析公开可见的视频内容，不涉及付费墙或订阅限制内容的访问。

## ✨ 核心功能

- 🔗 **链接解析**：支持标准 NYTimes 文章/视频页面链接，自动识别公开视频资源
- 📥 **多格式导出**：
  - 公开视频流（支持平台提供的公开清晰度选项）
  - 音频提取 → MP3 格式（便于离线收听新闻播报/播客内容）
  - 视频片段 → GIF 动图转换（适合制作教学素材/内容摘要）
- 🌍 **多语言支持**：内置中/英等语言界面，方便不同地区用户使用
- 📱 **全平台兼容**：适配 Chrome / Firefox / Safari / Edge 等主流浏览器，支持移动端访问
- 🔒 **隐私保护**：无需登录纽约时报账号，不收集用户个人信息，解析过程匿名化
- ⚡ **高效处理**：平均 5-10 秒内完成资源解析，支持并发请求

## 🚀 快速开始

### 在线使用（推荐）
1. 访问 [https://twittervideodownloaderx.com/nytimes_downloader_cn](https://twittervideodownloaderx.com/nytimes_downloader_cn)
2. 复制目标视频页面链接（如：`https://www.nytimes.com//01/01/world/example-video.html`）
3. 粘贴至输入框 → 点击「解析」按钮
4. 选择所需格式 → 按浏览器指引保存文件

### 本地部署（开发者）
```bash
# 克隆项目
git clone https://github.com/your-repo/nytimes-video-parser.git

# 安装依赖
cd nytimes-video-parser && npm install

# 配置环境变量（可选）
cp .env.example .env

# 启动服务
npm run dev
```

> 💡 部署说明：项目采用 Node.js + Express 架构，详细部署文档请参阅 `/docs/DEPLOY.md`

## 📚 使用指南

### 基础操作
```
1. 获取视频链接
   └─ 在纽约时报网站打开目标文章/视频页面 → 复制浏览器地址栏 URL

2. 提交解析
   └─ 粘贴链接至工具输入框 → 点击「开始解析」

3. 选择输出配置
   ├─ 🎬 下载视频：选择可用清晰度（仅限公开内容）
   ├─ 🎵 提取音频：生成 MP3 文件（适合新闻/播客离线收听）
   └─ 🎞 生成 GIF：截取指定时间段生成动图（建议≤15秒）

4. 保存文件
   └─ 浏览器新标签页打开资源 → 右键/菜单 →「另存为」
```

### 移动端提示
- iOS Safari：点击分享按钮 →「存储到文件」
- Android Chrome：长按视频预览 →「下载视频」
- 如遇自动播放：点击播放器右上角 `⋮` → 选择「下载」

## ❓ 常见问题

**Q：下载的文件保存在哪里？**  
A：默认保存至浏览器设定的下载目录，可在浏览器设置中查看或修改路径。

**Q：支持付费订阅或会员专享内容吗？**  
A：不支持。本工具仅能解析公开可见的视频资源，需遵循原内容的访问权限设置。付费墙、订阅限制或登录后可见的内容不在支持范围内。

**Q：转换后的画质/音质会损失吗？**  
A：视频下载为所选清晰度的原始码率；MP3 采用 128kbps 标准编码；GIF 会根据时长自动优化帧率，平衡体积与流畅度。

**Q：工具会缓存我的下载内容吗？**  
A：不会。所有资源均通过临时代理直传至您的设备，服务器不存储任何用户请求或媒体文件。

**Q：遇到解析失败怎么办？**  
A：请检查：① 链接是否为有效公开视频页面 ② 网络环境是否稳定 ③ 尝试更换浏览器。如问题持续，欢迎提交 Issue 反馈。
