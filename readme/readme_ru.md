## 📋 Обзор проекта

Этот проект представляет собой веб-инструмент для анализа видео, предназначенный для безопасного извлечения метаданных медиаресурсов из публично доступных статей на сайте The New York Times с возможностью конвертации форматов и локального сохранения. Не требует установки клиентского ПО или регистрации аккаунта — используйте напрямую через браузер.

## ✨ Основные функции

- 🔗 **Анализ ссылок**: Поддержка стандартных URL статей/видеостраниц NYTimes; автоматическое распознавание публично доступных видеоресурсов
- 📥 **Экспорт в нескольких форматах**:
  - Публичные видеопотоки (поддерживает общедоступные опции разрешения, предоставляемые платформой)
  - Извлечение аудио → Формат MP3 (удобно для прослушивания новостных репортажей/подкастов офлайн)
  - Видеофрагмент → Конвертация в анимированный GIF (идеально для создания учебных материалов/кратких обзоров контента)
- 🌍 **Многоязычный интерфейс**: Поддержка русского, английского, китайского, японского, корейского и других языков
- 📱 **Кроссплатформенная совместимость**: Полная поддержка Chrome / Firefox / Safari / Edge; оптимизированный опыт для мобильных устройств и планшетов
- 🔒 **Приоритет конфиденциальности**: Вход в аккаунт NYTimes не требуется, личные данные не собираются; процесс анализа полностью анонимен
- ⚡ **Высокая скорость обработки**: Анализ завершается в среднем за 5-10 секунд; поддержка параллельных запросов

```bash

cd nytimes-video-parser && npm install

cp .env.example .env

# Запустить сервер разработки
npm run dev
```

## 📚 Руководство по использованию

### Базовый рабочий процесс
```
1. Получить ссылку на видео
   └─ Откройте целевую статью/видеостраницу на NYTimes → Скопируйте URL из адресной строки браузера

2. Отправить запрос на анализ
   └─ Вставьте ссылку в поле ввода инструмента → Нажмите 「Начать анализ」

3. Выбрать конфигурацию вывода
   ├─ 🎬 Скачать видео: Выбрать доступное разрешение (только публичный контент)
   ├─ 🎵 Извлечь аудио: Создать файл MP3 (идеально для прослушивания новостей/подкастов офлайн)
   └─ 🎞 Создать GIF: Сгенерировать анимацию из указанного временного диапазона (рекомендуется: ≤15 секунд)

4. Сохранить файл
   └─ Ресурс откроется в новой вкладке → Правый клик/меню → 「Сохранить как」
```

### Советы для использования на мобильных устройствах
- iOS Safari: Кнопка «Поделиться» → 「Сохранить в Файлы」
- Android Chrome: Долгое нажатие на превью видео → 「Скачать видео」
- Если видео воспроизводится автоматически: Нажмите `⋮` в правом верхнем углу плеера → Выберите 「Скачать」

## ❓ Часто задаваемые вопросы

**В: Где сохраняются загруженные файлы?**  
О: Файлы сохраняются в папку загрузок, настроенную в вашем браузере. Вы можете проверить или изменить этот путь в настройках браузера.

**В: Можно ли анализировать контент за платной стеной, эксклюзивный для подписчиков или требующий входа в систему?**  
О: Нет. Этот инструмент работает только с публично доступным видеоконтентом и уважает настройки доступа к исходному контенту. Контент за платной стеной, с ограничениями подписки или требующий входа в систему не поддерживается.

**В: Снижается ли качество изображения/звука после конвертации?**  
О: Загрузки видео сохраняют исходный битрейт выбранного разрешения. Формат MP3 использует стандартное кодирование 128 кбит/с. Формат GIF оптимизирует частоту кадров в зависимости от длительности для баланса между размером файла и плавностью.

**В: Сохраняется ли история загрузок или кэш?**  
О: Нет. Все ресурсы передаются непосредственно на устройство пользователя через временный прокси; сервер не хранит никакие запросы или медиафайлы.

**В: Что делать, если анализ не удался?**  
О: Пожалуйста, проверьте: ① Соответствует ли ссылка действительной публичной видеостранице ② Стабильно ли ваше интернет-соединение ③ Попробуйте использовать другой браузер. Если проблема сохраняется, не стесняйтесь сообщить об этом через Issue.
