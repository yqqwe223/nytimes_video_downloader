## ✨ الميزات الرئيسية

- 🔗 **تحليل الروابط**: دعم روابط مقالات/صفحات فيديو NYTimes القياسية؛ الكشف التلقائي عن موارد الفيديو المتاحة للجمهور
- 📥 **تصدير بتنسيقات متعددة**:
  - بثوث فيديو عامة (يدعم خيارات الدقة العامة التي توفرها المنصة)
  - استخراج الصوت → تنسيق MP3 (ملائم للاستماع للتقارير الإخبارية/البودكاست دون اتصال)
  - مقطع فيديو → تحويل إلى صورة متحركة GIF (مثالي لإنشاء مواد تعليمية/ملخصات محتوى)
- 🌍 **واجهة متعددة اللغات**: دعم اللغة العربية والإنجليزية والصينية واليابانية والكورية والمزيد
- 📱 **توافق متعدد المنصات**: يعمل بسلاسة على متصفحات Chrome / Firefox / Safari / Edge؛ تجربة مُحسّنة للأجهزة المحمولة والألواح اللوحية
- 🔒 **الخصوصية أولاً**: لا حاجة لتسجيل حساب NYTimes، لا يتم جمع بيانات شخصية؛ عملية التحليل مجهولة الهوية بالكامل
- ⚡ **معالجة سريعة**: يكتمل التحليل في متوسط 5-10 ثوانٍ؛ دعم للطلبات المتزامنة

## 🚀 البدء السريع

### الاستخدام عبر الإنترنت (موصى به)
1. انتقل إلى [https://twittervideodownloaderx.com/nytimes_downloader_ar](https://twittervideodownloaderx.com/nytimes_downloader_ar)
2. انسخ رابط صفحة الفيديو المستهدفة (مثال: `https://www.nytimes.com//01/01/world/example-video.html`)
3. ألصق الرابط في حقل الإدخال → انقر على زر 「تحليل」
4. اختر التنسيق المطلوب → احفظ الملف باتباع إرشادات المتصفح

### النشر المحلي (للمطورين)
```bash
# استنساخ المستودع
git clone https://github.com/your-repo/nytimes-video-parser.git

# تثبيت التبعيات
cd nytimes-video-parser && npm install

# تهيئة متغيرات البيئة (اختياري)
cp .env.example .env

# تشغيل خادم التطوير
npm run dev
```

> 💡 ملاحظة: يستخدم هذا المشروع بنية قائمة على Node.js + Express. راجع وثائق النشر التفصيلية في `/docs/DEPLOY.md`

## 📚 دليل الاستخدام

### سير العمل الأساسي
```
1. الحصول على رابط الفيديو
   └─ افتح المقالة/صفحة الفيديو المستهدفة على NYTimes → انسخ عنوان URL من شريط عناوين المتصفح

2. إرسال طلب التحليل
   └─ ألصق الرابط في حقل إدخال الأداة → انقر على 「بدء التحليل」

3. اختيار تكوين الإخراج
   ├─ 🎬 تنزيل الفيديو: اختر الدقة المتاحة (محتوى عام فقط)
   ├─ 🎵 استخراج الصوت: إنشاء ملف MP3 (مثالي للاستماع للأخبار/البودكاست دون اتصال)
   └─ 🎞 إنشاء GIF: توليد رسوم متحركة من نطاق زمني محدد (موصى به: ≤15 ثانية)

4. حفظ الملف
   └─ سيتم فتح المورد في علامة تبويب جديدة → نقرة بزر الماوس الأيمن/القائمة → 「حفظ باسم」
```

### نصائح للاستخدام على الأجهزة المحمولة
- نظام iOS (متصفح Safari): زر المشاركة → 「الحفظ في الملفات」
- نظام Android (متصفح Chrome): اضغط مطولاً على معاينة الفيديو → 「تنزيل الفيديو」
- في حالة التشغيل التلقائي للفيديو: انقر على `⋮` في الزاوية العلوية اليمنى من المشغل → اختر 「تنزيل」
